# Rawedio (Awedio Fork)

A low-overhead and adaptable audio playback library for Rust.

Forked from [Awedio](https://github.com/boppofun/awedio), modified for
my purposes. I highly recommend using Awedio over my personal fork, it's
truly awesome work and this fork will probably fall behind!
